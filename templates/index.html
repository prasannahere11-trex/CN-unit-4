🎓 UniPort Viva Quick Reference

Port Number Ranges:

Well-Known (0-1023), Registered (1024-49151), Dynamic/Ephemeral (49152-65535).

Resolution Logic:

Maps transport layer ports to applications using ports.json. Prioritizes lower server ports over ephemeral client ports.

Security Rules:

Monitors plaintext services (Telnet/FTP), unknown high ports, and rapid port scan fanouts (>20 ports in 10s).

Privacy & Ethics:

Inspects headers only (IPs, Ports, Size). Never decodes or stores user payloads. Use only on authorized networks.
